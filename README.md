🌍 AthiSoft Travel Website
Welcome to the AthiSoft Travel Website repository! This project is a modern, responsive, and user-friendly travel platform designed to help users explore destinations, plan trips, and book travel services with ease.

✨ Features
🧭 Explore top travel destinations
🖼️ High-quality images and layout
📱 Responsive design (mobile-friendly)
🔍 Search and filter functionality
🗺️ Interactive sections for destinations, packages, and more
🧩 Smooth navigation with animations and effects

🚀 Technologies Used
Frontend: HTML5, CSS3, JavaScript, Bootstrap

🚀 Getting Started
# Clone the repository
git clone https://github.com/athisoft/Travel-Website.git

# Navigate to the project folder
cd athi-travel-site

# Open in your browser
start index.html  # Windows
open index.html   # macOS
